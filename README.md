# projeto-integrador---song-manager-
#introdução 
Este documento tem como objetivo apresentar proposta de desenvolvimento de uma plataforma digital acessível e intuitiva,voltada para facilitar a conexão direta entre músicos e contratantes. A intenção do projeto é apresentar uma plataforma organizada e segura para que os músicos possam se cadastrar e os contratantes encontrem músicos compatíveis com os estilos musicais de sua preferência.
